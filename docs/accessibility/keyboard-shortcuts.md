# Keyboard Shortcuts — CCSHAU Public Site

## Global

| Key | Action |
|-----|--------|
| **Tab** / **Shift+Tab** | Move focus between interactive elements |
| **Enter** / **Space** | Activate buttons and links |
| **Escape** | Close open modal, mobile menu, or desktop dropdown |

## Skip navigation

| Key | Action |
|-----|--------|
| **Tab** (first focus on page) | Reveals “Skip to content” link — **Enter** jumps to `#main-content` |

Admin: first **Tab** reveals “Skip to admin content” → `#admin-main-content`.

## Header

| Control | Keys |
|---------|------|
| Language toggle | **Enter** / **Space** |
| Accessibility toolbar | **Tab** to each button; **Enter** toggles font size, theme, contrast, reset |
| Mobile menu button | **Enter** opens menu; **Escape** closes and returns focus to button |
| Search fields | Type query, **Enter** submits |

## Main navigation (desktop)

| Key | Action |
|-----|--------|
| **Enter** / **Space** on item with submenu | Open/close dropdown |
| **Escape** | Close open dropdown or mega menu |
| **Tab** | Move through visible links |

## Homepage carousel

| Key | Action |
|-----|--------|
| **Tab** to carousel region, then **←** / **→** | Previous / next slide |
| **Tab** to slide dots, **Enter** | Jump to slide |

## Gallery lightbox

| Key | Action |
|-----|--------|
| **Escape** | Close viewer |
| **←** / **→** | Previous / next image (when multiple images) |
| **Tab** | Cycle focusable controls inside viewer |

## Faculty profile dialog

| Key | Action |
|-----|--------|
| **Escape** | Close dialog |
| **Tab** | Cycle focus inside dialog (focus trapped) |

## Listings (news, tenders, circulars, downloads)

| Key | Action |
|-----|--------|
| **Tab** to filter chips, **Enter** | Apply category/status filter |
| **Tab** to pagination, **Enter** | Go to previous/next page |

## Contact / feedback form

| Key | Action |
|-----|--------|
| **Tab** | Move between fields |
| **Enter** in single-line fields | Submit form (browser default) |

## Reduced motion

Users with **prefers-reduced-motion: reduce** at the OS level receive minimal animations (marquee, ken-burns, fade-up disabled).
